Explore

Interface preview with generated frames. The app shows real SPHEREx images for the target you search.

Two exposures of one place usually see different wavelengths.

Each detector sits behind a linear variable filter, so the wavelength changes along one axis of the image. A star lands on a different part of the filter each visit.

That means a brightness difference between two dates may be the star's spectrum, not a change. The app shows the wavelength at the target on every frame, and refuses a difference image unless both frames saw the same one.
