How SPHEREx sees

One pointing, six detectors

Each detector sits behind a linear variable filter, so the wavelength changes along one axis of the image. Every pointing gives six images at once, one per band.

Getting started

How it works

  1. Search

    A name, or coordinates in decimal, sexagesimal or galactic form.

  2. Timeline

    Every frame from QR2 and QR3, grouped into passes and pointings.

  3. Compare

    Blink, side by side, or a difference when the wavelengths match.

  4. Measure

    Brightness as a spectrum, or over time at one matched wavelength.
